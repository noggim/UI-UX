# 새 검·손 추적·걷기 실제 적용 (2026-10-27)

> **2026-10-28:** H3에서 걷기 그림을 다시 만들고 네 자세 재생 순서와 약한 추가 상하 움직임을 적용했다. 검·손 추적은 유지한다. 최신 걷기와 확장된 검수 실행기는 [H3 적용 기록](HERO_WALK_CYCLE_RUNTIME.md)을 따른다.

사용자 후속 요청으로 H2의 C1~C3를 `haeseong/game`의 실제 렌더러에 연결했다. 새 검은 그림 파일 준비 상태를 넘어 장착 무기에 따라 게임에서 표시된다. C4 임시 고정 손 위치는 실제 좌표 연결로 대체했다.

- `HeroAtlasData`가 자세별 손과 검별 손잡이·축척을 읽고 검증한다. `HeroMotionAtlas`가 검 8종을 한 번 로드하고 용사와 같은 mipmap/linear 필터를 사용한다. 텍스처도 아틀라스와 함께 해제한다.
- `WorldRenderer`는 실제로 표시한 `HeroPose`의 손을 검 회전 중심으로 쓴다. 좌우 반전, 몸의 공격 변형과 상하 움직임을 함께 적용한다. 공격·스킬·채굴 중에도 손잡이가 손에 남는다.
- 걷기/서기는 한 자세씩 표시한다. 기존 프레임 혼합으로 생기던 이중 머리·다리를 제거했다. 구르기의 시작/복귀 혼합과 의도된 돌진 잔상은 유지하되 구르는 동안 검을 숨긴다.
- ~~정면 대기 검은 110°로 바깥쪽에 세워 얼굴을 가리지 않는다.~~ (2026-10-27 변경) 대기 검은 손에서 아래·바깥쪽으로 내려 든다(정면 220°). 칼날이 손이나 머리 위로 올라오지 않는다. 걷기 자세 순서는 `walkCycle`을 따른다 ([GPT_HERO_WALK_CYCLE.md](GPT_HERO_WALK_CYCLE.md)). 왼쪽 방향은 대응 각도를 사용하고 위쪽 방향에서는 기존처럼 몸 뒤에 그린다. 새 봉인 성검에는 사슬을 중복해서 그리지 않는다.
- `ActorInk`에서 새 용사만 외곽 폭 0.45월드px, 외곽 농도 0.20과 약한 명암 보정을 적용한다. 다른 배우와 세계 조명은 그대로다.
- `-Dyongsa.heroArt=legacy` 비교 모드는 기존 용사·검 표시를 사용한다. 가방/제작/HUD의 전용 무기 그림은 기존 용도대로 유지한다.

## 검증과 재현

연결 시점 Java17 `:core:test :lwjgl3:dist` 통과: **134개 테스트, 실패/오류 0**. 새 회귀 검증은 원본 손 좌표가 실제 자르기·반전·공격 변형과 일치하는지, 8종 무기/성검 형태가 알맞게 선택되는지, 잘못된 부착 좌표를 거부하는지 확인한다. 공격·스킬·채굴의 복귀 곡선도 8방향 대기 각도로 검증했다.

```powershell
.\gradlew.bat :core:test :lwjgl3:dist
java -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.HeroEquipmentLauncher build/h2-runtime-captures
```

검수 도구는 실제 게임 렌더러를 사용하며 별도 저장 폴더와 숨겨진 창으로 실행된다. CAMP/L3/R1/T3 × 8방향 × 8동작(두 보폭, 서기, 공격, 스킬, 채굴, 구르기, 구르기 복귀), 검 8종 × 두 방향, 두 방향 걷기 연속 60장으로 **총332개 화면**을 확인했다. 전체 플레이 대신 고정 위치·동작 타이머를 사용한 시각 검증이다. 이 실행에서 GL 오류는 없었다.

검수 이미지와 GIF는 로컬 `build/h2-runtime-captures/` 및 `design/hero-sword-runtime/`에 남긴다. 기존 사용자 결정대로 새 검수 이미지는 Git에 올리지 않는다.
