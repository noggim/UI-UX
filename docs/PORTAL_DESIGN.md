# 보스방 귀환문과 마왕 진입부 — 2026-11-01

보스방 위쪽에 캠프 던전 입구와 같은 계열의 돌 아치를 상시 배치한다. 보스 처치 전에는 기존 던전별 장벽(광산 목재·성채 철창·탑 마력)이 닫혀 있고, 처치하면 장벽이 내려가면서 열린다. 열린 문 앞에서 E를 누르면 캠프로 귀환한다.

## 귀환문

- `assets/world/portals/return-door.png`: 캠프 북쪽 돌 아치를 참고해 내장 `image_gen`으로 만든 투명 문틀. 기존 `sprites/gate_LEFT/RIGHT/TOP.png` 장벽을 그대로 재사용한다. 열린 문틀은 계속 남는다.
- `natural-room-scenes.json`의 `returnDoor` 좌표를 렌더링·상호작용·미니맵이 함께 사용한다. 광산 `[0.5, 0.335]`, 성채 `[0.5, 0.245]`, 탑 `[0.5, 0.235]`다.
- 원본 해상도 1280×1280, 월드 표시 크기 180×180. PNG 바이트와 투명도를 그대로 보존했다. [생성 프롬프트](portal-design-generation.json).
- 보스 처치·방 클리어 조건은 유지한다. 보스 재생성 시 다시 닫힌다. 장벽은 약 0.55초에 걸쳐 내려가며, 기둥 밑동과 닫힌 장벽만 이동을 막는다. 아치 전체 그림을 충돌 영역으로 삼지 않는다.
- 중앙의 바닥 귀환진·원형 빛·상승 입자는 렌더링하지 않는다. 보상 상자는 기존 방 중앙 근처에 남는다. 처치 안내문과 미니맵 표시는 위쪽 귀환문을 가리킨다.

## 캠프의 마왕 진입부

`abyss-sealed.png`와 `abyss-open.png`는 기존 적용을 유지한다. 세 보스의 힘에 따라 봉인석 보석이 켜지며, 봉인 해제 후 계단과 심연이 드러난다. 중심은 원화 `[0.506, 0.700]`이다. E로 진입하며 자동 추락 규칙은 없다. 캠프 원화와 이동 마스크는 이번 작업에서 수정하지 않았다.

## 가림 검토 도구

기존 `haeseong/mask-review`의 원화 73장에 이동 판정과 별개인 가림 편집·용사 미리보기를 추가했다. 기존 원화 다각형 41개, 연결부 다각형 5개, 앞벽 이미지 11개를 가져와 **32장**에 초안을 표시한다. 데이터가 없는 41장은 빈 상태로 두고 추가 표시할 수 있게 했다. 앞쪽 가장자리 초안은 항상 가림, 기둥 등은 밑동 기준 가림으로 제안한다.

게임의 기존 가림 영역을 바꾼 것은 아니다. 사용자 검토 JSON을 받은 뒤 적용한다. 미리보기의 희미한 용사 실루엣 역시 검토용이며 게임에 새 윤곽선 기능을 적용한 상태는 아니다. 초안 내보내기 재현: `python tools/export_layer_review.py ../yongsa-mask-review`.

## 검증

Java 17 `:core:test :lwjgl3:dist` 통과, 테스트 146개 실패·오류 0. 세 문까지의 바닥 도달성, 닫힌 장벽의 발 충돌, 처치 후 개방과 E 귀환, 보스 재생성 시 닫힘을 검사한다. 기존 전체 방·계단·출입구 도달 검사도 열린 문 기준으로 유지한다.

```powershell
.\gradlew.bat :core:test :lwjgl3:dist
java '-Dfile.encoding=UTF-8' -cp lwjgl3/build/libs/yongsa-game-0.1.0.jar com.yongsa.lwjgl3.PortalDesignLauncher build/return-door-final
```

캡처 실행기는 별도 QA 세이브를 사용하며 캠프 6상태·세 던전 열린 문·세 던전 닫힌 문을 용사 위치 3곳씩 총 36장 렌더한다. 캡처와 검토 파일은 로컬 build에만 둔다. 자동 검증은 전체 캠페인 수동 플레이를 대신하지 않는다.
