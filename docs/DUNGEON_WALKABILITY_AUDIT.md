# 던전 그림·이동 판정 전수 점검 (2026-10-27)

실제 그림에는 바닥·계단이 있는데 바닥 경계가 안쪽으로 잡혀 진입하지 못하는 부분을 수정했다. 그림 파일을 다시 그리지 않고 현재 그림에 맞춰 이동 가능한 다각형을 보정했다. 방 배치, 연결 관계와 저장 맵 버전은 바꾸지 않았다.

## 점검 범위

현재 배치된 **83개 영역 전체**를 실제 렌더러 화면과 용사 발 판정으로 비교했다.

| 영역 | 수 | 범위 |
| --- | ---: | --- |
| 방 | 28 | CAMP, L1~L8, R1~R7, T1~T7, V, F, CAVE_LEFT/RIGHT/TOP |
| 그림 통로 | 20 | 광산·성채·탑의 모든 배치, 좌우 반전 포함 |
| 출입구 덧그림 | 35 | 모든 entry/exit 연결 그림 |

활성 출입구 **53곳**의 도착 위치가 용사 발 크기로 통과 가능하고 방 안에서 도달 가능한지 확인했다. 캠페인 진행·전투 문 잠금 검증은 기존 테스트와 함께 실행했다.

## 수정한 바닥 정의 8개

| 정의 / 위치 | 수정 |
| --- | --- |
| mine-mob-c / L1 | 뒤쪽 세 계단의 보이는 디딤판과 착지 공간까지 확장 |
| mine-junction / L8 | 왼쪽 계단과 앞쪽 넓은 바닥을 절벽 직전까지 확장 |
| citadel-boss-a / R6 | 중앙 제단으로 올라가는 계단까지 확장, 양쪽 조각상 받침은 막힘 유지 |
| mine-traverse / L1–L2, L5–L7 | 보관 공간 앞 비어 있는 바닥까지 확장 |
| mine-rail-bend / L3–L4 | 레일 북동쪽의 열린 바닥까지 확장, 상자 영역은 막힘 유지 |
| mine-descent / L1–L8, L2–L3, L3–L5, L7–L6 | 횃불 옆 빈 공간을 확장. 반전 배치와 인접 통로 그림의 겹침도 확인 |
| exit-L2-L3 | 왼쪽 계단 디딤판과 아래 착지 공간을 그림에 맞춤 |
| exit-R5-R6 | 성채 계단 아래 왼쪽으로 이어지는 바닥 경계를 확장 |

덧그림의 반투명 가장자리에서는 상단 그림이 절반 이상 보이고 그 위치가 바위인 경우, 아래의 옛 바닥으로 통과시키지 않는다. 이전에는 광산 통로를 확장하면 덧그린 바위 아래 바닥까지 노출됐다. 상단 그림이 바닥이면 기존 연결 판정을 유지한다. 이 규칙을 적용하며 성채의 실제 열린 왼쪽 진입 바닥도 함께 보정했다.

## 의도적으로 막혀 있는 곳

- L2의 `west`는 연결 대상이 없는 폐쇄 출구이며 잔해로 표시된다. 현재 활성 출구는 `west2`와 `south`다.
- 전투 중 문, 진행 조건으로 잠긴 던전, 절벽·상자·제단 양쪽 받침은 통과시키지 않는다.
- 덧그림으로 교체된 부분은 원래 통로 그림의 바닥 좌표를 그대로 열지 않고 실제 최상단 그림을 기준으로 판단한다.

## 검증

`DungeonWalkabilityTest`는 그림 검수로 선정한 계단·착지점·빈 공간을 검사하고, 방 내부를 4월드px 간격으로 탐색해 활성 출입구에 도달하는지 확인한다. 용사 발 반폭 9·반높이 6을 사용한다. 수정된 방의 여섯 경로는 실제 `Physics.move`로 왕복한다. 절벽·상자·폐쇄 출구·전투 잠금과 덧그린 바위가 열리지 않는지도 확인한다.

기존 통로 중심선 2px 간격 검사, 그림끼리 바닥을 가리는지 검사, 출입구 통과와 전체 캠페인 이동 검사도 통과했다. 전체 Java17 `:core:test :lwjgl3:dist`: **138개 테스트, 실패/오류 0**.

로컬 전수 점검은 83개 영역의 4px 격자 마스크를 실제 화면에 겹쳐 검수했다. 경계 격자의 작은 조각은 탐색 시작점에 따라 CAMP/L3와 일부 통로 덧그림에 남지만, 활성 출입구나 이동 중심선이 끊기는 구간은 없었다. 이 검사는 고정 화면과 이동 판정의 비교이며 플레이어가 처음부터 끝까지 조작한 플레이 테스트는 아니다.

```powershell
.\gradlew.bat :core:test :lwjgl3:dist
```

검수 화면·마스크·점검용 로컬 스크립트는 `design/dungeon-route-audit/`에 보관한다. 새 검수 이미지는 기존 사용자 결정대로 Git에 올리지 않는다. 실제 게임에 필요한 변경은 JSON 바닥 경계, WorldMap 충돌 처리, 회귀 테스트에 포함된다.
