# 새 용사에 검·걷기 맞추기 — GPT 작업 지시 (2026-10-27, 묶음 H2)

> **적용 완료:** 사용자의 후속 요청 “일단 그럼 적용 한번 해줘”에 따라 S1~S3 자산에 이어 C1~C3도 실제 게임에 연결했다. C4 임시 고정 위치는 실제 손 좌표 연결로 대체했다. [현재 적용·검증 기록](HERO_SWORD_RUNTIME.md)을 따른다. 아래 분담은 최초 작업지시 당시 기록이다.

`cec76f0`의 새 용사(3/4 시점, 3.5~4등신)는 맵과 잘 어울린다. 사용자 결정: **검을 용사에 맞춘다** (용사 도트를 낮추지 않는다). 이 문서는 그 후속 작업이다. GPT는 S1~S3 그림 작업을 하고, C1~C4 코드 작업은 Claude가 한다.

## 지금 문제

실제 게임에서 방향별 걷기를 60Hz로 찍어 확인했다 (카메라를 용사에 맞춤).

1. **검만 다른 그림처럼 보인다.** 용사는 부드러운 고해상도 그림(원본 키 약 280px → 게임 약 58px)인데, 검(`assets/world/sword_*.png`)은 예전 굵은 도트 그림이다. 몸이 가늘어져서 검이 상대적으로 크다 (게임에서 40×40월드px 칸).
2. **검이 손에 붙어 있지 않다.** 새 용사 시트는 빈손이다. 코드가 모든 자세에서 같은 자리(몸 중심에서 옆 10px, 위 20px)에 검을 세워 그린다. 걸을 때 팔이 흔들려도 검은 제자리라 "떠 있는" 느낌이 난다. 대각선·뒷모습에서 특히 어긋난다.
3. **걷기가 미끄러지듯 보인다.**
   - 앞·뒤 걷기는 프레임 사이 다리 움직임이 작아서 발을 끌며 미끄러지는 느낌이다.
   - 옆·대각선 걷기에서 **앞뒤 프레임을 반투명으로 섞어 그려서 머리·다리가 두 겹으로 보이는 순간**이 있다 (코드 문제, C1).
   - 앞 대각선 자세가 정면·옆보다 조금 커 보이고 웅크려 있어 방향을 틀 때 키가 바뀐다.

## GPT 그림 작업

### S1. 검 8종을 새 용사 화풍으로 다시 그리기

- 대상: 흑철검·혈월검·천공검·성검 각각 일반/각성, 8장. 이름은 지금과 같다: `sword_blackiron`, `sword_blackiron_awakened`, `sword_bloodmoon`, `sword_bloodmoon_awakened`, `sword_skyfall`, `sword_skyfall_awakened`, `sword_holy`, `sword_holy_awakened`.
- 새 파일 위치: `assets/sprites/hero-motion/harmony/swords/<이름>.png` (예전 `assets/world/` 파일은 덮어쓰지 않는다).
- 화풍: `harmony/walk.png`의 용사와 **같은 해상도·같은 붓 터치·같은 조명**(위쪽 따뜻한 빛, 아래 차가운 그림자, 짙은 갈색 얇은 외곽선). 굵은 도트 금지.
- 크기: 용사 원본과 같은 축척. 칼날+손잡이 길이가 **용사 원본 키의 약 55%**(원본 키 약 280px 기준 150px 안팎). 칸은 정사각형, 투명 배경.
- 방향: 지금처럼 **손잡이가 왼쪽 아래, 칼끝이 오른쪽 위로 45°**. 손잡이 끝(쥐는 자리 가운데) 좌표를 각 파일마다 적는다 (S3).
- 검마다 색과 모양은 지금 그림을 따른다 (흑철=검은 철·푸른빛, 혈월=붉은 초승달 문양, 천공=하늘색·번개, 성검=금색 손잡이·흰 칼날, 각성은 빛나는 문양 추가).

### S2. 걷기 다듬기 (`harmony/walk.png`, `harmony/walk-diag.png`)

- 앞·뒤 걷기: 6프레임에서 **다리를 더 크게 교차**(발 하나가 다른 발보다 확실히 앞에 나온 자세 2장 포함)하고 몸이 위아래로 조금 오르내리게. 팔도 다리와 반대로 흔든다.
- 앞·뒤 대각선: 정면·옆과 **같은 키·같은 머리 크기**로 맞춘다. 웅크린 느낌을 줄이고 등을 편다.
- 손: 검을 쥘 손(오른손)은 **주먹을 쥔 모양**으로 그려서 손잡이가 들어갈 자리를 만든다. 검은 그리지 않는다 (게임이 그린다).
- 파일 규격·프레임 순서·발 기준은 `assets/data/hero-motion.json`의 지금 계약을 그대로 지킨다. 크기가 바뀌면 JSON의 영역·해시를 함께 갱신한다.

### S3. 손 위치 표시 (코드 연결용)

`assets/data/hero-motion.json`의 걷기·구르기 모든 프레임에 **`hand`: 쥔 주먹 가운데의 원본 픽셀 좌표 [x, y]** 를 추가한다. 각 검 PNG에는 `swords` 항목에 손잡이 좌표 `grip: [x, y]` 를 넣는다. 이 두 값이 있으면 Claude가 매 프레임 검을 손에 붙여 팔과 같이 흔들리게 만든다.
