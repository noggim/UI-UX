# 용사가 다한다 · 그래픽 인수인계 (GPT 협업용)

이 문서는 다른 AI(GPT 등)나 디자이너가 **게임 그림을 새로 그리거나 다듬을 때** 필요한 내용을 모은 것입니다.
코드는 Claude(Claude Code)가 맡고, 그림은 이 문서 규칙대로 만들어 주면 바로 게임에 들어갑니다.

같이 받는 파일:
- `current_sprites_sheet.png`: 지금 게임에 들어 있는 그림 전부 (4배 확대, 이름과 크기 표시)
- `current_sprites/`: 지금 그림 원본 PNG (실제 크기). 이 파일을 고쳐서 돌려주면 제일 쉽습니다.
- `screenshots/`: 실제 게임 화면
- `GAME_SPEC.md`: 지금 게임 전체 명세 요약 (이야기, 맵, 전투, 대장간, 수치)

---

## 1. 게임 한눈에 보기

- **장르:** 2D 탑다운 액션 RPG, 실시간 전투 (Windows 데스크톱, Java 17 + libGDX)
- **시점:** 코어 키퍼(Core Keeper)처럼 비스듬히 내려다보는 2.5D. 캐릭터는 정면/뒷면/옆면이 보이는 3/4 시점 픽셀 아트.
- **이야기:** 버려진 던전 한가운데 캠프에서 용사가 혼자 대장장이 일까지 다 한다. 집안 대대로 내려온 **봉인된 성검**을 들고 시작한다. 던전 세 곳의 보스를 쓰러뜨려 그 힘을 흡수하면 봉인을 풀 수 있고, 깨어난 성검으로만 마왕을 이길 수 있다.
- **맵:** 가운데 캠프(대장간, 침대, 모닥불) + 왼쪽·오른쪽·위 던전 3개. 던전은 방이 이어진 구조(엔터 더 건전처럼). 몬스터방, 광물방, 보스방.
- **NPC 없음, 포션 없음, 돈 없음.**

| 던전 | 이름 | 분위기 | 광물 / 무기 | 잡몹 | 보스 |
|---|---|---|---|---|---|
| 캠프 | 용사의 캠프 | 따뜻한 흙바닥, 모닥불 | - | - | - |
| 왼쪽 | 무너진 갱도 | 회색 돌, 무너진 광산, 차가운 푸른빛 | 흑철석 / 흑철검 (검푸른 쇠) | 갱도 박쥐 (bat) | 갱도를 삼킨 골렘 (golem) |
| 오른쪽 | 저주받은 성채 | 붉은 벽돌, 피 같은 달빛, 뼈 | 혈월석 / 혈월검 (붉은 보석) | 저주받은 해골병 (skeleton) | 혈월의 기사 (knight) |
| 위 | 마왕의 탑 | 보라색 돌, 룬, 마력 | 천공석 / 천공검 (하늘색 결정) | 탑의 마족병 (imp) | 탑의 수문장 (warden) |
| 위 끝 | 최종 보스방 | 보라·금색 | - | - | 마왕 (demonlord) |

무기 각성(+10 강화): 심연의 흑철검, 만월의 혈월검, 뇌명의 천공검. 성검은 봉인된 성검 → 깨어난 성검.

## 2. 꼭 지켜야 하는 기술 규칙

1. **픽셀 아트, 투명 배경 PNG.** 안티앨리어싱(부드러운 테두리), 반투명 픽셀은 쓰지 않는다. (그림자 `shadow`만 예외)
2. **크기를 정확히 지킨다.** 아래 목록의 크기(예: 16x20)가 그림 1픽셀 단위다. 게임은 그림 1픽셀을 화면 3픽셀로 크게 그린다. 크기가 다르면 화면에서 크기가 달라진다.
3. **파일 이름을 바꾸지 않는다.** `hero_down.png`처럼 목록의 이름 그대로. 이름 끝을 `_숫자`로 끝내면 안 된다 (`walk_2` ✗, `walk2` ✓).
4. **밝게 그린다.** 게임이 조명(어두운 던전 + 횃불 빛)을 위에 곱해서 어둡게 만든다. 그림 자체는 중간~밝은 톤으로, 너무 어둡게 그리지 않는다. 검은 외곽선(#1b1b24)을 쓰면 어두운 곳에서도 잘 보인다.
5. **방향과 기준점:**
   - 캐릭터·몬스터는 **발이 그림 맨 아래 줄**, 가운데 정렬. 몸이 그림 아래 가운데에 서 있어야 한다.
   - 옆모습(`hero_side`)과 몬스터는 **오른쪽을 본다.** 왼쪽은 게임이 좌우 반전해서 쓴다.
   - 검(`sword_*`)은 **칼날이 오른쪽 위 45도**, **손잡이가 왼쪽 아래**. 손잡이 잡는 점은 왼쪽 아래에서 (3,3) 픽셀 근처. 게임이 이 점을 중심으로 돌려서 휘두른다.
   - 바닥·벽 타일은 16x16, 이어 붙였을 때 이음매가 티 나지 않게.
6. **조명 색은 게임이 낸다.** 불꽃, 광맥, 포탈 주변 빛 번짐은 코드가 그린다. 그림에는 빛 번짐을 넣지 말고 물체만 그린다.

## 3. 그림 넣는 방법

### 방법 A: PNG 파일 (추천)
`assets/sprites/이름.png` 로 넣으면 게임이 원래 그림 대신 그 파일을 쓴다. 코드는 고칠 필요 없다.
파일을 빼면 원래 그림으로 돌아간다. `current_sprites/` 의 PNG를 고쳐서 같은 이름으로 주면 된다.

### 방법 B: 글자 그림 (sprites.txt)
`assets/data/sprites.txt` 는 글자 한 개가 픽셀 한 개인 그림 파일이다.
```
palette k 1b1b24ff        ← 글자 k = 색 #1b1b24 (RRGGBBAA)
sprite hero_down 16 20    ← 이름 너비 높이
.....kkkkkk.....          ← 다음 줄부터 높이만큼, 각 줄은 너비만큼. '.' 은 투명
```
지금 팔레트: `k 1b1b24`(외곽선) `s f2c79a`/`S cf9a6c`(피부) `h 6b4226`/`H 4a2c18`(머리) `r c0392b`/`R 8e2a20`(빨강) `b 3d6fb6`/`B 2b4f86`(파랑 옷) `g 8a5a2b`(가죽) `p 3b3b52`(바지) `w f4f1e8`/`W c9c4b8`(흰색) `y f2c94c`/`Y c28f1e`(금) `n 2a2a33` `m 6e6e7a`/`M 4a4a55`(회색 돌·쇠) `o 9aa6c8`/`O dfe6ff`(칼날·광물, 무기마다 다른 색으로 바뀜) `v 7b4fb3`/`V 4e2d78`(보라) `c 8c1e2d`/`C 5c1020`(진홍) `x e8443a` `z 2f8a4f`(초록) `l 9b6a3c`/`L 6b4826`(나무) `f ff9c2a`/`F ffd75e`(불).
새 색이 필요하면 `palette 글자 색` 줄을 추가하면 된다.

### 큰 그림으로 받았을 때
이미지 생성기로 크게 만든 그림(예: 512x640)은 정확한 픽셀이 아니라서 그대로 쓰면 흐리다.
그런 그림은 **디자인 시안**으로 보고, Claude에게 주면 정해진 크기로 줄이고 픽셀을 정리해서 넣는다.
가장 좋은 결과는 정해진 크기 그대로 한 픽셀씩 찍은 그림이다.

## 6. 앞으로 바뀌는 것 (참고)

- 회전 베기·돌진 베기는 뺐다. 지금 조작은 **베기(J) + 구르기(스페이스)**.
- 무기를 각성하면 스킬이 늘거나 **검기가 날아가는** 식의 추가 공격이 붙을 예정 → 검기·스킬 이펙트 그림이 필요해진다.
- 맵은 나중에 더 커질 예정.

## 7. 작업 순서 제안

1. `current_sprites_sheet.png` 와 `screenshots/` 를 보고 **전체 아트 방향**(팔레트, 외곽선, 명암 규칙)을 먼저 정한다.
2. ★★★ 부터: 용사 → 바닥·벽 타일 → 몬스터 → 캠프 물건 → 무기 → 광물.
3. 한 묶음씩 PNG로 만들어 사용자에게 준다. 사용자가 Claude에게 넘기면 게임에 넣고 화면을 찍어 확인한다.
4. 화면에서 어색하면 다시 고친다.
