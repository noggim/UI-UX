# 김선우(noggim) 몬스터 패턴 그림

모든 시트는 **256px 칸 × 8열**이고, 그림은 **왼쪽**을 봅니다. 발(바닥)은 칸의 (128, 224)입니다.
몬스터 몸과 효과(검기·탄·구체·돌·창·충격파·번개·촉수)는 **따로** 있습니다.
게임은 몸 동작을 넘기다가, 실제로 공격이 나가는 순간에만 효과를 그립니다.
그리는 코드는 `core/.../enemy/PatternArt.java`에 있습니다.

## 보스 패턴 시트 (패턴 하나 = 한 줄)

예고하는 동안 앞 4칸(준비), 공격이 나간 뒤 뒤 4칸(던지기·휘두르기 → 회복)을 넘깁니다.

| 파일 | 줄 |
|---|---|
| `boss_golem_patterns.png` | 0 연속 돌진 · 1 연속 내려찍기 · 2 바위 던지기 · 3 기절 |
| `boss_knight_patterns.png` | 0 혈월 검기 · 1 창 솟기(멈춤) · 2 회전 베기 · 3 뒤로 도약 · 4 방패 |
| `boss_lich_patterns.png` (마왕 1페) | 0 어둠 구체 · 1 고리 탄 · 2 낙인 |
| `boss_lich2_patterns.png` (마왕 2페) | 0 촉수 · 1 심연의 눈 |
| `boss_warden_patterns.png` | 0 대기(앞 4칸)·걷기(뒤 4칸) · 1 번개 감옥 · 2 유도 마탄 · 3 불꽃 회전 · 4 소환 |

## 효과 시트 `fx_patterns.png` (5줄)

| 줄 | 칸 |
|---|---|
| 0 | 혈월 검기 0~3 · 땅에서 솟는 창 4~7 |
| 1 | 어둠 구체 0~3 · 마탄 4~5 · 낙인 마법진 6~7 |
| 2 | 유도 구체 0~3 · 불덩이 4~7 |
| 3 | 바위 0~3 · 충격파 4~7 |
| 4 | 콩알탄 0~1 · 작은 불덩이 2~3 · 번개 벽 4~5 · 촉수 6~7 |

투사체와 검기는 날아가는 방향으로 돌려 그리기 때문에 위·아래·대각선 어느 쪽으로 쏴도 맞게 보입니다.
몸은 용사 쪽으로 좌우를 뒤집습니다.
